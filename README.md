# MNZS | BloxStrike

Versão 9.18.

Cole esta linha no executor:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/playfael/bloxstrike-script/main/BloxStrike.luau"))()
```

O menu usa **Right Shift** por padrão. Configurações, temas e skins são salvos localmente pelo script.

`BloxStrike.luau` contém o script completo com as imagens dos oito temas. Não é necessário baixar as imagens separadamente.
